# Glow Website

This is a responsive website built using React and Tailwind CSS. Products in this website are fetched from [DummyJSON](https://dummyjson.com/products).

## Features

- Responsive design
- Mobile menu toggle
- React router navigation
- Tailwind CSS styling
- Lucid React icons
- API data fetching
- React hooks usage
- Hover states for interactive UI
- Skeleton loading states while fetching data

## Technologies Used

- React
- Tailwind CSS
- React Router DOM
- Lucid React
- Vite
- DummyJSON API

## Installation

1. Clone the repository
   - git clone [https://github.com/pramms19/eco-project.git](https://github.com/pramms19/eco-project.git)
2. Install dependencies
   - npm install
3. Run the project
   - npm run dev
